# RWGN03-RPS 原型确认表（系统一致版）

本表以研究提案、机遇观测两条现行流程为准。只有形式审查可退回申请人修改；技术评审、科学评审提交建议，科学委员会最终选择通过或驳回。评审意见默认不向申请人公开，系统管理员可对单个提案切换公开状态；页面与完整提案 PDF 遵守同一设置。

| 功能需求编号 | 场景描述 | 用户角色 | 原型演示方案 | 操作路径 | 预期结果 |
| --- | --- | --- | --- | --- | --- |
| RWGN03-RPS-01 | 提案在线申请 | 提案者 | 选择研究提案或机遇观测提案，填写名称、摘要、申请内容、观测目标、仪器参数，上传附件；保存本人草稿、返回工作区续写、正式提交。 | 登录 → 工作区 → 研究提案/机遇观测 → 创建新提案；草稿可从本人列表继续编辑。 | 草稿保存在本人账号，管理员与其他用户不可查看；正式提交后显示提案编号并进入**形式审查**；已提交内容不能按草稿修改，形式审查退回后可修改并重新提交。 |
| RWGN03-RPS-02 | 目标可见性及观测时间计算 | 提案者 | 输入目标名称、赤经、赤纬、日期与仪器，查看外部服务返回的计算结论。 | 登录 → 工作区 → 目标可见性计算；也可在申请中按需调用。 | 仅辅助申请，不是审批节点。**外部计算服务尚未完成，完整观测窗口与条件结果暂不作为本次原型验收项。** |
| RWGN03-RPS-03A | 提案与流程管理 | 系统管理员 | 查看全部已提交提案；维护用户、角色、流程、表单、仪器与类型；在技术、科学及最终决策阶段分配相应人员。 | 登录 → 管理区 → 全部提案/流程管理/用户/角色/表单。 | 可查看已提交提案与全部已提交评审意见，不查看他人草稿；不代替专家评分。技术、科学阶段至少分配一人，且**本阶段所有已分配专家提交后**，管理员才能确认推进。 |
| RWGN03-RPS-03B | 技术评审 | 技术评审专家 | 阅读本人获分配的提案和附件，填写技术评分、技术意见及“建议通过/建议驳回”。 | 登录 → 工作区 → 评审任务 → 技术评审提案。 | 仅获分配且处于技术评审阶段者能提交；提交形成评审记录，不自动推进，也不进行科学价值评分；不提供评审阶段退回修改。 |
| RWGN03-RPS-03C | 科学评审 | 科学评审专家 | 阅读本人获分配的提案和附件，填写科学评分、评语及“建议通过/建议驳回”。 | 登录 → 工作区 → 评审任务 → 科学评审提案。 | 仅获分配且处于科学评审阶段者能提交；提交形成评审记录；所有已分配专家提交后由管理员推进至最终决策。 |
| RWGN03-RPS-03D | 最终决策 | 科学委员会 | 获分配的委员查看提案及已提交的技术、科学评审意见，填写综合优先级、决策理由，选择通过或驳回。 | 登录 → 工作区 → 评审任务 → 最终决策提案。 | 通过：研究提案进入**待分配观测数据**，机遇观测提案进入**观测编排与执行**；驳回则结束。此阶段不退回修改。 |
| RWGN03-RPS-03E | 评审意见公开控制 | 系统管理员 | 在提案详情查看全部已提交评审与决策记录，并切换“向申请者公开/对申请者隐藏”。 | 登录 → 管理区 → 全部提案 → 提案详情 → 评审与决策记录。 | 默认隐藏；管理员可按提案控制。申请者页面与其下载的完整提案 PDF 均按该设置显示，管理员始终可查看。 |
| RWGN03-RPS-03F | 观测数据分配 | 提案管理员 | 在数据处理完成后选择已通过评审的研究提案及仪器，登记数据编号、产品名称、格式、摘要和链接。 | 登录 → 工作区 → 数据分配 → 选择提案 → 确认分配。 | 系统只显示“待分配观测数据”，不增加“待数据处理”节点；管理员手动分配后变为“数据已授权”。单项分配可演示；未填链接时可生成临时测试数据。 |
| RWGN03-RPS-03G | 观测编排 | 观测编排负责人 | 仅处理已推送的机遇观测提案，记录观测窗口、安排、执行状态和结果摘要。 | 登录 → 工作区 → 观测反馈 → 待编排提案。 | 可先保存安排而不结束阶段；提交最终结果后进入申请人结果确认。**观测完成时间由系统在提交“观测已完成”结果时自动记录**，无需手工填写；不负责科学评审或研究提案数据授权。 |
| RWGN03-RPS-04A | 观测执行反馈 | 观测编排负责人 | 对每项申请仪器记录“已安排观测/观测已完成/当前无法执行”、观测窗口和结果或原因。 | 登录 → 工作区 → 观测反馈 → 选择机遇观测提案。 | 所有仪器形成最终结果后，提案进入“执行反馈”，申请人可查看并确认收到；实际完成时间自动留痕。 |
| RWGN03-RPS-04B | 数据访问与结果确认 | 提案者 | 研究提案查看已授权数据产品与访问链接；机遇观测提案查看执行摘要；确认收到结果。 | 登录 → 本人工作区 → 选择本人提案 → 已开放数据/观测结果。 | 研究提案授权后可见数据编号、摘要与下载入口；未授权前不显示数据产品。机遇观测不自动分配数据，仅反馈执行结果。 |

验收时应分别使用提案者、两类评审专家、获分配的科学委员会委员、系统管理员、提案管理员和观测编排负责人账号，覆盖“未分配、部分提交、全部提交、意见隐藏、意见公开、两类通过/驳回”情形；外部可见性计算服务不纳入本轮闭环验收。
