# 版本记录

本文件记录鸿蒙计划 RPS 原型的功能变化。前端与后端使用同一版本号；网站导航显示当前前端版本。

## 0.2.0 — 原型确认后迭代（2026-11-12）

- 提案申请：研究提案与机遇观测提案统一在“提案申请”中；支持草稿、分步填写、附件和正式提交。
- 提案批次：管理员设置申请起止时间及数据释放最晚时间；新提案须选择开放批次，相关截止时间限制提交和数据授权修改。
- 评审与执行：按角色处理技术评审、科学评审、委员会决策、观测编排反馈和数据分配。
- 科研成果：获得数据后的提案可提交成果及论文初稿，进行站内公示和意见反馈，随后提交修改稿供科学委员会认定，并记录投稿与最终发表版。
- 界面：统一主要工作区入口和列表样式，并在导航中显示版本号。

## 0.1.0 — 初始原型基线

- 提案申请、评审流程及管理功能的初始版本。

版本号表示代码功能版本，不单独证明某一环境已完成部署；部署时仍需确认运行中的版本。
